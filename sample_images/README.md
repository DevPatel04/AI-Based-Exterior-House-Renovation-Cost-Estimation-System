# Sample exterior photos for testing

Free Unsplash house exteriors (download for local upload tests).

| File | Best for |
|------|----------|
| `house_suburban_front.jpg` | Clear front wall + windows (recommended first test) |
| `house_modern_white.jpg` | Clean modern facade, good SegFormer/ControlNet |
| `house_two_story.jpg` | Multi-level massing / roof edge |
| `house_brick_facade.jpg` | Brick texture / cladding redesign |
| `house_contemporary.jpg` | Luxury contemporary exterior |
| `house_cottage.jpg` | Tall portrait crop; windows + door |

**How to use:** create a project → upload one of these from this folder → Detect structure → materials → Visualize → Estimate.
