# System limitations

- Designed for low-rise residential exteriors only; not interiors or structural engineering.  
- Area estimates from a single photo are approximate; perspective and occlusion introduce error.  
- AI structure detection may miss or mislabel regions — user correction is required.  
- Without Gemini/Cloudflare API keys, redesign uses a local visual fallback (not photoreal).  
- Gemini image HQ mode is optional and may require paid API access.  
- Cloudflare FLUX reference inputs may require resized images under provider limits.  
- Cost rates are seed/defaults and must be updated for local markets.  
- Not a substitute for professional surveys, permits, or contractor quotes.
