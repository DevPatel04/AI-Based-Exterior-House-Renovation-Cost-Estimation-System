# User workflows by role

## Homeowner
1. Register / login as homeowner  
2. Create project → upload exterior photo  
3. Review quality guidance; retake if rejected  
4. Run structure detection; correct regions  
5. Apply materials per region; generate redesign  
6. Enter optional facade size; calculate cost  
7. Download PDF report for contractor discussion  

## Contractor / Architect / Builder / Consultant
1. Register with professional role (or receive share invite)  
2. Open shared or owned project  
3. Adjust regions, quantities, and/or rates per permissions  
4. Review redesign and totals  
5. Download report for quotation / client review  

## Material supplier
1. Login as supplier  
2. Open Catalog  
3. Add materials with rates, coverage, wastage  
4. Wait for admin approval if required  

## Admin
1. Login as admin (`admin@renovation.local` after seed)  
2. Assign roles under Admin  
3. Approve supplier materials  
4. Access all projects and system settings
